# EVRKare / UniFrame v0.2

- Yakalama ve işlem arasında 256×144'e küçültme kaldırıldı; kaynak çözünürlüğü korunur.
- Tekrar Kare, Karışık Kare (Harmanlama), Hareket Telafili Ara Kare ve Otomatik modlar ayrı sunulur.
- Karışık Kare ağırlığı basit menüden ayarlanabilir.
- Tekrar için doğrudan RGB, CPU harmanlama için RGBA dönüşümsüz hızlı yol eklendi.
- Hareket tahmininde CPU luma hesapları kaynak çiftinde tekrar kullanılır.
- Kaynak pencere yeniden boyutlandığında motor yeni boyutla yeniden açılır.
- İşleme çözünürlüğü, pipeline süresi ve lookahead ayrı gösterilir.
- Full HD kaynak piksel koruması, harmanlama ve gerçek ara kare testleri eklendi.

Linux paketinde çalışma zamanı dahildir. Windows paketi Python/Tk gerektirir;
Windows ikilileri çapraz derlenmiş, Windows üzerinde çalıştırılmamıştır.

Bu hâlâ ayrı pencere önizleme prototipidir. Oyunun swapchain'ine kare eklemez.
CPU/yazılım Vulkan Full HD interpolasyonu gerçek zamanlı oyun performansı değildir.
Fiziksel GPU, 1440p/4K kalite/performans ve input-to-photon testleri yapılmadı.
AFMF 2.1'in özel algoritmaları veya performansıyla eşdeğerlik iddia edilmez.

Harmanlanmış görüntüler `blended_count` / `blended_completed` olarak ayrı
sayılır; `generated_count` hareket telafili yeni ara karelere ayrılmıştır.
